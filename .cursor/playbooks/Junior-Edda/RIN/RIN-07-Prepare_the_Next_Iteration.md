# Activity: Prepare the Next Iteration

**Activity ID**: 559
**Order**: 7
**Phase**: Construction
**Dependencies**: Predecessor: Activity 558 (Raise Iteration Improvement Proposals)

## Description

Prepare the Next Iteration

## Guidance

## Objective

Close the current iteration cleanly and leave an evidence-based entry condition for the next one.

## Required inputs

Iteration Frame, retrospective, IIPs, Project-Management Tickets, latest AIN report, Charter, backlog, and release evidence.

## Procedure

1. Disposition every IIP as accepted, rejected, deferred, or still under review; name owner and decision date.
2. Update the Charter only for approved changes to goals, ownership, maturity, variables, artifact coverage, cadence, or roadmap. Add a dated change log.
3. Carry forward open Risk/Problem tickets with current evidence and gating policy; do not duplicate them.
4. Record a short ordered list of candidate next goals, dependencies, capacity constraints, and mandatory ticket work.
5. Close the current Iteration Frame with actual end time, result, release identifier, assessment report, and unresolved concerns.
6. State the next-entry condition. Do not automatically start a new iteration or pre-authorize its goal.

## Completion evidence

The current frame is closed; Charter changes are approved and versioned; every IIP/ticket has a disposition or owner; candidate goals are ordered but not falsely committed; and the next RIN run can begin from the recorded entry condition.

## Agent

**Name**: Delivery Manager (DM)
**Description**: Single merged PM/DM role. Staffed at Kickoff. Owns the Charter, is the recipient of all Risk/Problem tickets raised by Assess the Iteration, presides over cadence meetings, and determines iteration cadence/length.
