# Activity: Assign the Delivery Manager

**Activity ID**: 546
**Order**: 1
**Phase**: Kickoff
**Dependencies**: Successor: Activity 547 (Absorb Vision/Scope Handover)

## Description

Assign the Delivery Manager

## Guidance

## Objective

Have the project sponsor appoint the Delivery Manager before the Delivery Manager performs any project work. An AI agent must not appoint itself or infer a person.

## Procedure

1. Obtain the sponsor's explicit appointment.
2. Record it in `docs/project/DELIVERY_OWNERSHIP.md` with:
   - Delivery Manager name and contact;
   - start date and timezone;
   - decision authority and approval boundaries;
   - escalation route and response expectation;
   - backup/delegate;
   - responsibility for Charter ownership, cadence, AIN oversight, and Risk/Problem tickets.
3. Confirm the appointee accepts the role.
4. If no person is available, record the sponsor as interim DM with an expiry/review date; do not leave ownership implicit.

## Completion evidence

The assignment record exists, names both sponsor and DM, contains authority boundaries, and includes appointment and acceptance timestamps. Staffing is a human/sponsorship action; the activity deliberately has no executing Mimir Agent.
